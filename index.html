claude-diag

Generate a local Claude Code diagnostic report with sensitive values redacted before anything is shown or shared.

script 
curl -fsSL https://sh.cdiag.link | bash
  • Runs locally The bootstrapper downloads the Python script and hands off on your machine.
  • Stdlib only The diagnostic script is a single Python file with no package install step.
  • Redacted first Tokens, keys, public IPs, emails, and local paths are masked in the report.

The script prompts before it runs diagnostics. Review source before piping any shell command into your terminal.
