## Overview

`cdiag.link` is the public Astro site for `claude-diag`, including the landing page and install command:

```sh
curl -fsSL https://sh.cdiag.link | bash
```

## Development

Install dependencies:

```sh
bun install
```

Run the local dev server:

```sh
bun dev
```

Check and build:

```sh
bun run check
bun run build
```

## Stack

- Astro
- Bun
- Svelte
- TypeScript
- UnoCSS
